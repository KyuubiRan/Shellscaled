受限命令

本机执行

仅允许 tailscale 与 tailscaled 的受限子命令。其他程序、管道、重定向与命令替换会被拒绝。

支持的命令与参数格式

tailscale 支持 status / ip / version / netcheck / ping / up / down / set / login，以及 --help / --version。tailscaled 仅支持 --help / --version。

参数值使用 --flag=value；不支持引号、变量或换行。ping 最多 5 次，每次最多 5 秒。外部 socket、SSH、文件传输、调试、自更新和外部程序配置均不可用。

例如选择退出节点：tailscale set --exit-node=设备名称或IP。
